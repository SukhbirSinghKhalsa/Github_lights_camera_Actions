runners --> place where all our commands will be running

There are 2 types of runners
1. Self-hosted   --> we will install one agent in our local system or VM and run all our pipeline commands in it

Concept:
- we will have one software configured in some system -- physical laptop, or Virtual machine

Advantage:
- Full control
- All the files which will be generated by our pipeline are visible to you
- Security - no 3rd party dependencies

Disadvantage:
- it needs to online 24 * 7
- we need to do all the patching work by ourselves


2. Github-Hosted
- predefined agent provided by github --> SaaS
- 2 types
a) windows-latest --> windows OS --> powershell
b) ubuntu-latest  --> linux OS    --> bash


## from where to setup our first self-hosted agent in github?
--> Go to Settings on your repo -->
--> Go to Code and automation section
--> Expand Actions & you will see Runners 
--> click on Runners
--> click green button having title as "New Self-Hosted Runner"
